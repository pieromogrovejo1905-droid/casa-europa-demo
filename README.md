# Demo Casa Europa · Free Marketing

Demo para la propuesta 2027 de Casa Europa: landing de la promoción, chatbot de WhatsApp simulado y panel de administración.

- `index.html`: landing
- `whatsapp.html`: simulador del chatbot (registro, lectura de boletas, duplicados, costo de WhatsApp)
- `panel.html`: panel con reportes, validación manual, respuestas editables y roles

Todo corre en el navegador (localStorage); no hay servidor. Las fotos de productos se cargan desde casaeuropa.pe.
